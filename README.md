# Остров кристаллов

Лёгкая 3D-игра: бегайте по острову и собирайте кристаллы. Управление: левый палец — идти, правый — камера, кнопка «Прыжок». Экран поддерживает поворот (портрет и ландшафт).

## Как получить APK через GitHub
1. Создайте репозиторий на GitHub и загрузите в него все файлы из этого архива, включая папку `.github/workflows`.
   Если папка `.github` не загружается, создайте файл вручную: Add file → Create new file, имя `.github/workflows/build.yml`, вставьте содержимое из `build.yml`.
2. Откройте вкладку Actions → Build APK → Run workflow (или просто сделайте commit в ветку main).
3. Через 3–5 минут откройте завершённый запуск и скачайте архив `crystal-island-apk` в разделе Artifacts. Внутри файл `app-debug.apk`.
4. Распакуйте, скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).
